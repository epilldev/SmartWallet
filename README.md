# SmartWallet

SmartWallet é um aplicativo iOS focado no gerenciamento de despesas pessoais, desenvolvido com tecnologias modernas do ecossistema Apple e uma estrutura simples e organizada.

## Visão Geral

O aplicativo foi desenvolvido para estudos e com o fim proporcionar uma experiência prática e eficiente no controle de despesas pessoais diretamente no dispositivo.

Utilizando SwiftUI e Core Data, o projeto segue uma estrutura modular com separação de responsabilidades, facilitando manutenção, evolução e escalabilidade.

---

## Funcionalidades

* Cadastro de despesas
* Persistência local de dados
* Visualização de informações financeiras
* Interface desenvolvida com SwiftUI
* Experiência nativa para iOS
* Estrutura simples e organizada

---

## Tecnologias Utilizadas

| Tecnologia | Finalidade                   |
| ---------- | ---------------------------- |
| Swift      | Linguagem principal          |
| SwiftUI    | Desenvolvimento da interface |
| Core Data  | Persistência local           |
| Xcode      | Ambiente de desenvolvimento  |
| iOS SDK    | Suporte nativo para iOS      |

---

## Persistência

O SmartWallet utiliza Core Data para armazenamento local das despesas, garantindo persistência nativa e integração com o ecossistema Apple.
